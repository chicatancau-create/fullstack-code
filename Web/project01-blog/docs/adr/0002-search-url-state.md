# ADR 0002：搜索状态放在 URL

- 状态：接受
- 日期：2026-11-07

## 背景

首页搜索需要可分享、可前进/后退，并且刷新后保留关键词。

## 选项

1. 组件内 `useState`：实现简单，但刷新/分享/后退丢失搜索词。
2. 全局状态库：跨页保留，但引入依赖与同步问题。
3. URL `?q=` + `useSearchParams`：浏览器历史天然支持，链接可分享。

## 决定

采用 3。输入变化直接更新 `?q=`；空查询移除参数。

## 代价

- 每次输入都写历史（没有 debounce/replace），后退可能逐步回退字符；内容量大时应改为 `replace` 或防抖。
- URL 会变长；敏感搜索词不应放 URL（本博客无敏感数据）。

## 验证

`tests/app.test.tsx` 断言搜索后 location 为 `/?q=HTTP`，列表从 3 变 1。
