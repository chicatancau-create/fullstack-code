# 缺陷修复记录

## T-01 过期会话仍可用

- 根因：`requireUser` 的 SQL 只匹配 `s.token`，漏掉 `s.expires_at > now()`；登录时虽写入过期时间，但读取端不校验。
- 修复：恢复过期条件，过期令牌返回 401。
- 回归：登录后把 `expires_at` 改为过去时间，`GET /me` 断言 401。

## T-02 跨工作区任务泄漏

- 根因：任务列表路由直接按 `workspace_id` 查询，删除了 `memberOf` 校验；详情/创建/更新仍有校验，所以只有列表泄漏。
- 修复：恢复成员校验，非成员统一 404（不泄露工作区是否存在）。
- 回归：alice 建任务，bob 读取同一路径断言 404；alice 自己仍能读到 1 条（基线）。

## T-03 最后 owner 可被删除

- 根因：删除成员只校验请求者角色，删除了“目标为 owner 时统计 owner 数”的分支；工作区可变为 0 owner。
- 修复：在已有事务与工作区行锁内统计 owner，最后一名 owner 返回 409。
- 回归：唯一 owner 删除自己断言 409，并查询数据库确认 owner=1。

## 取舍

- 保持原 API 契约与状态码，不做顺手重构；修复只覆盖报告缺陷。
- 未把会话令牌改为哈希（会影响既有数据/契约），列入交接风险。
- 并发删 owner 未新增测试；行锁已在原实现中，顺序回归只证明计数保护生效。
