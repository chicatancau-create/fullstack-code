# Bug 复盘 001：搜索词在返回首页后丢失

- 日期：2026-11-07
- 严重度：中（可用性）
- 状态：已修复

## 现象

从首页搜索 `HTTP` → 打开详情 → 浏览器后退，搜索框变空、列表恢复 3 篇。

## 根因

搜索词存在 `Home` 组件的 `useState`；路由切换时组件卸载，状态丢失。不是浏览器缓存或 React 渲染问题。

## 修复

把搜索词迁移到 URL `?q=`，用 `useSearchParams` 读写。返回/刷新/分享都会保留。

## 回归

- 组件测试：搜索后 location 包含 `?q=HTTP`，列表 1 条。
- E2E：输入 HTTP 后 `1 篇笔记`，进入详情成功。

## 遗留

输入每个字符都 push 历史；内容规模变大时应改为 `replace` 或防抖，并评估后退体验。
